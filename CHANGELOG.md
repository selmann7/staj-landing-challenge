# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-23

### Added
- Initial project structure with React, TypeScript, and SCSS.
- Core UI components: Button, Input, Card, Modal, Accordion.
- Landing page sections: Hero, Features, Pricing, FAQ, Contact.
- Theme management (Dark/Light mode) using `useTheme` hook and CSS variables.
- Responsive design with three breakpoints (Mobile, Tablet, Desktop).
- Form validation for the Contact section using plain TypeScript.
- Accessibility features (semantic HTML, ARIA labels, focus states).
- Documentation: README, ADR-001, and CHANGELOG.
